# Ejercicios de práctica en Python

Este repositorio reúne ejercicios y pequeños proyectos que realicé durante mi etapa inicial de aprendizaje en Python.  
No sigue una estructura estricta porque fue creado a lo largo del tiempo, mientras exploraba lógica de programación, manejo de archivos y conceptos básicos.

Aunque no está organizado por carpetas ni fechas exactas, lo conservo porque forma parte de mi evolución técnica.

## Contenido del repositorio

Incluye archivos relacionados con:

- Bucles, condicionales y estructuras básicas
- Manejo de funciones
- Lectura y escritura de archivos (.txt, .csv)
- Simulación de una agenda de contactos
- Ejercicios de repaso por fechas
- Scripts de práctica y pruebas personales

## Archivos destacados

- `main.py` — script principal de pruebas
- `agenda_de_contactos.py` — pequeña agenda telefónica en Python
- `creacion_csv.py` / lector_csv.py — manejo de archivos CSV
- `Ejercicios_variables.py` / if_for_while.py — ejercicios básicos
-` 09_05_25_repaso.py` / 13_05_2025.py — ejercicios por fecha
