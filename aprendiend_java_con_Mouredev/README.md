# Aprendiendo Java con Morived

Este repositorio contiene ejercicios básicos realizados durante mi aprendizaje de Java,  
siguiendo el curso de Morived en YouTube.

Incluye ejemplos prácticos como:

- Imprimir texto en consola (`HelloWorld`)
- Uso de variables y constantes
- Operadores y expresiones
- Manipulación de cadenas (`StringExercises`)
- Estructuras de control (`Main`)
- Ejercicios de repaso

---

##  Objetivo

Este proyecto forma parte de mi formación técnica.

##  Estructura del repositorio

Los archivos `.class` fueron generados a partir de los ejercicios en Java.  
Más adelante se pueden añadir los archivos `.java` originales para facilitar la lectura del código.
